- **Save HDR photos as a JPEG.** The new *JPEG HDR* file format keeps the highlights brighter than white, so they shine on screens and in programs that show HDR, and look as they always did everywhere else.
- **Save HDR photos as a TIFF for editing.** The new *TIFF HDR* file format keeps the brightest highlights as exact light values, for editing in programs such as Photoshop, Affinity, Krita and DaVinci Resolve.
